О YTP

Независимый видеоклиент с подключением Invidious и официальных аккаунтных функций Google.

Что сохраняется

Видеотека, избранное, история открытия и публичные параметры подключения хранятся в этом браузере. Очистка данных сайта удалит их. Личные подписки и плейлисты загружаются из Google после входа. Токен сессии хранится только в памяти вкладки.

Воспроизведение

С подключённым Invidious используется собственный плеер с запросом системного PiP. Без сервера работает официальный плеер YouTube с его рекламой и ограничениями. Спонсорские фрагменты не пропускаются. Premium и офлайн-загрузка не предоставляются. Фоновое воспроизведение и PiP зависят от устройства и режима браузера.

При использовании поиска, входа, обложек и плеера браузер обращается к сервисам Google. Запросы Data API используют квоту подключённого проекта.

Ваш YouTube

Войдите, чтобы открыть свои подписки и плейлисты.

Вход и выбор аккаунта происходят в официальном окне Google. Пароль вводится только у Google.

Выход здесь не завершает сеанс на youtube.com. Полная история и рекомендации YouTube не доступны этой оболочке через публичный API.

Подключение Google

Включите YouTube Data API v3 в Google Cloud. Добавьте домен сайта в ограничения API key и JavaScript origins OAuth-клиента типа Web application.

Эти параметры сохраняются в этом браузере. Не вставляйте Client Secret или access token.

Чтение: подписки и плейлисты. Изменения: оценки, подписки, плейлисты и публикация комментариев — только по вашему действию.
