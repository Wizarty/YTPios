# Worker без VPS

Worker в `worker/index.mjs` автоматически получает список публичных Invidious с API из `https://api.invidious.io/`, пробует до трёх серверов и проксирует API и объединённые медиапотоки. Это экспериментальный адаптер: живые публичные серверы и iPhone ещё не проверены. Worker не заменяет Invidious и не гарантирует доступность YouTube.

## Публикация владельцем (однократно)

1. В Cloudflare Dashboard откройте Workers & Pages → Create → Worker. Создайте Worker `ytpios-video`.
2. В редакторе замените пример полным содержимым `worker/index.mjs`, сохраните и опубликуйте. Зависимостей, секретов и базы данных нет. Origin по умолчанию — `https://wizarty.github.io`.
3. Скопируйте выданный HTTPS-адрес `https://ytpios-video.<ваш-поддомен>.workers.dev`.
4. В GitHub → Settings → Secrets and variables → Actions → Variables задайте `INVIDIOUS_URL` этим адресом. Pages Source должен быть GitHub Actions. Запустите workflow Publish GitHub Pages. Все новые посетители получат настройку автоматически; ручной ввод Invidious не нужен.
5. Если ранее сохраняли другой адрес или отключали сервер на устройстве, обновите адрес через шестерёнку сайта: локальная настройка имеет приоритет над сборкой.

Альтернатива Dashboard: из папки worker запустите Wrangler login/deploy в своей доверенной среде. Не публикуйте токен Cloudflare в Git или чате.

## Проверка после публикации

Откройте `<адрес Worker>/api/v1/trending`: ожидается JSON-массив, не HTML. Затем проверьте поиск и воспроизведение на сайте, перемотку (206/Content-Range), PiP и блокировку экрана на iPhone. Ошибка 503 означает отсутствие доступных источников; успешный deploy не доказывает работу видео.

## Границы

- Бесплатный тариф имеет квоты; проверить актуальные лимиты и условия Cloudflare перед использованием для видеотрафика. Бесконечное бесплатное проксирование не обещается.
- Поддержаны combined formatStreams; DASH и HLS не реализованы в Worker. Повторная загрузка метаданных при Range-запросах увеличивает нагрузку.
- Доступность реестра, API, видеопрокси, ограничения операторов и блокировки YouTube могут остановить воспроизведение. Ни один публичный сервер не гарантирован.
- Google OAuth остаётся прямым; Worker отклоняет Authorization/Cookie и не пересылает входящие credentials.
- CORS ограничивает браузеры, но не является защитой от внешних клиентов. При публичном использовании настройте ограничения запросов в Cloudflare, следите за расходом квоты.
- SponsorBlock и гарантированное фоновое воспроизведение iOS не добавляются этим прокси.
