# Собственный веб-плеер: первый этап

Откройте `https://wizarty.github.io/YTPios/player.html` при публикации Actions или `https://wizarty.github.io/YTPios/public/player.html` при публикации ветки. Ссылка «Плеер PWA» также есть в видеотеке.

Добавьте **эту страницу** на экран Домой и запустите иконку YTP Player. В комплекте двухминутное тестовое видео с тихим синусоидальным звуком, синтезированное FFmpeg специально для проекта. Можно выбрать собственный видеофайл: он не загружается на сервер.

Проверить на физическом iPhone:

1. Запуск в standalone (режим указан в «Результаты проверки»).
2. Воспроизведение со звуком.
3. Системный PiP через стандартный API или WebKit presentation mode; также кнопка PiP системного полноэкранного плеера, если доступна.
4. Переход в другое приложение и блокировка экрана: продолжается ли звук, работают ли медиакнопки.
5. Возврат и экспорт отчёта, с ручной записью фактического поведения и версии iOS.

Media Session не предоставляет разрешение на фоновое воспроизведение. Наличие метода PiP не доказывает работу в standalone. Автотест воспроизводит настоящий MP4 в Chromium, но не подтверждает iOS/PiP/звук заблокированного устройства.

Сервис-воркер сохраняет только файлы оболочки этой тестовой страницы. Видео, Google API, OAuth, запросы других страниц и пользовательские файлы он не кеширует. Отчёт содержит время событий, режим запуска, user agent и введённые пользователем заметки; не содержит OAuth-токенов, ключей и имени локального файла. Отчёт скачивается пользователем, автоматической отправки нет.

## Следующий этап

Основной сайт теперь содержит [адаптер Invidious](INVIDIOUS.md), способный получать видеопотоки от настроенного сервера. Сам сервер пока не развёрнут; эта тестовая страница по-прежнему работает с локальным MP4. Официальный Data API не возвращает прямые MP4/HLS-адреса. Для предложенного варианта необходим отдельный сервер с неофициальным извлечением публичного потока, ресурсами для обработки запросов и ограничением доступа. GitHub Pages не запускает такой сервер. OAuth остаётся только между браузером и Google: токены аккаунта нельзя отправлять извлекателю потоков.

До подтверждения работы собственного плеера на целевом iPhone и выбора серверного размещения не считать основную задачу выполненной. Блокировка рекламы и SponsorBlock в этот этап не входят.
