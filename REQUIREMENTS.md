# Обязательные требования пользователя

Сохранять эти требования при дальнейшей разработке и не считать текущий прототип завершённым продуктом.

- Использование в браузере iPhone/Safari и на других устройствах; предпочтительно без расширений и установки.
- Интерфейс максимально соответствует мобильному приложению YouTube.
- Пользовательский сценарий: официальное окно входа Google → свой YouTube-аккаунт в нашей оболочке, отображение подключённого канала, подписок и плейлистов. Настройка OAuth-клиента — задача владельца сайта, не каждого посетителя. Это независимый клиент официальных API, а не встраивание авторизованного youtube.com или общий сеанс cookies.
- Полная интеграция доступных функций официальных YouTube/Google: реальный поиск, данные видео и каналов, вход Google, подписки, плейлисты, оценки и комментарии в пределах публичных API и предоставленных разрешений.
- Изначальный запрос также включает отсутствие рекламы, пропуск спонсорских интеграций, фон, PiP и возможности Premium. Эти требования остаются открытыми: доступные официальные API не позволяют обещать их полную реализацию.
- Когда необходимы действия владельца Google Cloud, явно указать API, тип credentials, ограничения, разрешения и место настройки. Не запрашивать секретные значения в чате.
- Не подменять полную интеграцию демонстрационными данными, локальным избранным или ссылками на YouTube. Не выдавать проверки с подменённым API за проверку живого сервиса.

Текущий статус и необходимые внешние настройки: [docs/GOOGLE_INTEGRATION.md](docs/GOOGLE_INTEGRATION.md).
